Adeesh Desai

I am a Master’s student in Robotics at Purdue University and a Graduate Student Researcher in the MARS Lab, advised by Professor Yu She. My research focuses on learning-based manipulation and tactile sensing, developing intelligent manipulation systems through imitation learning (IL), reinforcement learning (RL), vision–language–action models (VLA), world-action models (WAMs), and multimodal sensory integration.

My current work spans tactile-enhanced manipulation for contact-rich tasks and cross-modal generative models for embodied AI. Earlier, I designed multirotor drone platforms at IIT Bombay’s e-Yantra lab.

Under Review, 2026

website / arXiv / video / code

TacImag learns to predict task-relevant tactile representations from visual observations, enabling touch-informed manipulation at deployment without physical tactile sensors.

ContactWorld: What Matters in Vision-Tactile World Models for Contact-Rich Manipulation
Zhiyuan Zhang*, Pokuang Zhou*, Kaidi Zhang, Adeesh Desai, Temitope Amosa, Davood Soleymanzadeh, Jiuzhou Lei, Minghui Zheng, Yu She
Under Review, 2026

website / arXiv / video / code

ContactWorld reveals that representation structure matters, tactile benefits depend on cross-modal compatibility, and tactile sensing becomes increasingly valuable for long-horizon planning.

CONTACT: CONtact-aware TACTile Learning for Robotic Disassembly
Yosuke Saka*, Jyun-Chi Hu*, Adeesh Desai*, Zhiyuan Zhang*, Bihao Zhang, Quan Khanh Luu, Md Rakibul Islam Prince, Minghui Zheng, Yu She
IEEE/RSJ International Conference on Intelligent Robots and Systems (IROS), 2026

website / arXiv / video / code

CONTACT reveals when and why tactile sensing matters for robotic disassembly, highlighting the effectiveness of structured tactile force-field representations in contact-dominated tasks.

Projects

ROS-Based Motion Planning & Trajectory Execution for Robotic Manipulation  · 2025
Implemented a ROS-based motion-planning pipeline converting Cartesian end-effector trajectories into time-parameterized joint-space plans via forward and inverse kinematics. Discretized continuous task-space trajectories (Lissajous curves) into 500 Hz joint trajectories compatible with real-time ROS controllers, enforcing joint, sampling-rate, and smoothness constraints. Validated end-effector paths in RViz and deployed on physical robot hardware for a full planning-to-execution workflow.
ROS · Motion Planning · Inverse/Forward Kinematics · Trajectory Planning · RViz · Real-time Control

Grocery Store Automation  · 2025
An autonomous robotic system for grocery automation, restocking empty shelves and returning misplaced products. Mounted a UR5 manipulator on a Pioneer3DX mobile robot (AMR) for pick-and-place, using depth-camera vision for 3D coordinate extraction and object recognition, inverse kinematics for manipulation, and path planning for collision avoidance. Multi-process integration synchronized AMR navigation with manipulator control.
UR5 · Pioneer3DX · AMR · CoppeliaSim · Path Planning · Machine Vision · Collision Avoidance · ROS

Warehouse Automation for Material Handling
Programmed a UR5 arm with Techno Machine Flow (TMFlow) to follow a safe trajectory for material handling, implementing vision-guided AMR localization and a fail-proof process flow. Built a LiDAR map of the workspace and set up waypoint navigation for a Freight 100 AMR in the Fetchcore cloud-based fleet-management software.
UR5 · TMFlow · AMR · LiDAR · Fetchcore · Fleet Management · Waypoint Navigation

Vision-Guided Sorting using UR5e
A complete vision-guided sorting system on the UR5e arm. Developed Python/OpenCV pipelines integrated with an Intel RealSense D415 depth camera for real-time object sorting and orientation tracking, enabling pick-and-place and visual servoing. Programmed via ROS for 5-DOF pick-and-place and 1-DOF visual servoing with inverse kinematics and smooth trajectory planning, validated in CoppeliaSim and on real hardware.
ROS · Python · OpenCV · UR5e · RealSense D415 · CoppeliaSim
